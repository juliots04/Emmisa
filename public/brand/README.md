# Marca Emmisa

Símbolo: **Acordeón Emisor** — papel plegado tipo fanfold de impresora fiscal; evoca la emisión continua de comprobantes.

## Archivos (todos SVG = 100% editables en Figma, Illustrator o en texto)

| Archivo | Cuándo usarlo |
|---|---|
| `badge.svg` | Ícono principal: favicon, ícono de app, avatar, redes. Símbolo dentro del badge índigo. |
| `mark.svg` | Solo el símbolo (duotono) sobre fondo **claro**. |
| `mark-white.svg` | Solo el símbolo en **blanco**, para fondos oscuros o de color. |
| `mark-mono.svg` | Símbolo a **una tinta** índigo (sellos, impresión 1 color). Cambia el `fill` para recolorear. |
| `logo-horizontal.svg` | Símbolo + nombre, en fila. Fondo **claro**. |
| `logo-horizontal-white.svg` | Símbolo + nombre, texto blanco. Fondo **oscuro**. |
| `logo-stacked.svg` | Símbolo arriba + nombre abajo. Para espacios cuadrados. |

## Colores de marca

- Índigo principal: `#6366f1`
- Índigo claro: `#818cf8` / `#a5b4fc`
- Índigo oscuro: `#4338ca` / `#4f46e5`
- Acento (opcional): ámbar `#f59e0b`
- Blanco: `#ffffff`

## Tipografía del nombre

Fuente propuesta: **Space Grotesk** (distintiva, no genérica). Está definida en los SVG y es cambiable — reemplaza `font-family` por la que elijas. Para un archivo 100% portable, convierte el texto a curvas (outline) en Figma/Illustrator.

## Cómo editar

Cada SVG es texto plano. Para cambiar el color, edita los valores `fill`/`stop-color`. Para otros formatos (PNG, ICO), abre el SVG en el navegador o en Figma y exporta al tamaño que necesites (16, 32, 180, 512 px…).
